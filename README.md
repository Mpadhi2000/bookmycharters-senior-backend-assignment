# BookMyCharters — Technical Assignment (Starter Pack)

This pack accompanies the assignment brief you received. **Please read the brief
first** — it explains what we are looking for and how to submit.

## What's in here

- **`assignment-1-cache-service/`** — a small, working Yii2 service. This is your
  starting point for Assignment 1. Setup steps and the API are documented in that
  folder's own `README.md`.

- **`assignment-2-incident/access-log-sample.log`** — the redacted Nginx access-log
  extract for Assignment 2. The same extract appears in the brief; it is provided
  here as a file so you can work with it directly.

## How to submit

Follow the Submission Guidelines in the brief. In short: return both assignments in a
single GitHub repository (preferred) or ZIP, keeping this two-folder layout —

```
assignment-1-cache-service/     (your modified service + DECISIONS.md)
assignment-2-incident/          (your technical proposal + any diagrams)
```

Each folder should contain its own short README so it can be reviewed on its own.

Good luck — we look forward to discussing your work in the live sessions.
